# Origin and release scope

Mousecat began as Marshmallow Commons, a local desktop view over project and machine state, and developed its own source observations, model identities and reviewed action engine. The original Mousecat interaction application is now [Marshmallow](https://github.com/ellyj3rain/marshmallow). Their histories and responsibilities remain distinct.

This public source is a deliberately selected application tree. Original private history, operational catalogs, personal records, retained machine data and undisclosed work remain separately preserved. The selected source retains the developed React/Electron interface, shared project interpretation, model registry, source continuity, MCP observations and content-bound plan/apply implementation.

The approval and remote-standing modules express the existing finite application behavior directly. Their public consumers preserve the existing content, destination, freshness, branch and uncertain-outcome protections. No private language sources or generated executable helpers are published; the separately unaccepted repository evaluator is not requalified through a rename or substitute implementation.

Examples and test observations are synthetic. The public source version is inherited from its source line and does not by itself establish complete product or installed-host acceptance. Release records identify actual changes and evidence rather than copying private operational narratives.
