# Governance-world proposal: public historical summary

The July 2026 examination proposed a persistent spatial world for understanding
project work. This is a historical proposal, not the current implementation
contract. CORE.md and ARCHITECTURE.md describe the implemented Mousecat surfaces.

A21 replaces the private consumer examination and raw interaction receipt with
this public summary. Private project ontology, research routes, operator prompts,
responses, continuation metadata and source dossiers remain outside public source.
The original private provenance is retained separately from the public release.

| Proposed element | Meaning |
|---|---|
| Project realms | Each project retains its repository, runtime, permission, history and checkpoint authority. |
| Authored geography | Places and paths support comprehension without manufacturing source relationships. |
| Persistent operator | Location, discoveries and save lineage can persist in a native client. |
| Situated decisions | World context can expose project decisions while their originating systems own truth and writes. |
| Source ontology | Engine, orchestrator, actor, persona, model, organization, seat, role, skill, tool, permission, memory and receipt retain their source-defined distinctions. |
| Verified progression | Changes follow actual understanding, decisions and verified source state. |
| Asset promotion | Distributable assets require explicit provenance and compatible licenses. |
| Checkpoints | A named save binds source, client, world and operator state through a validated manifest. |
| Initial proof | Exploration, source projection and save/load establish the world foundation before source-changing interactions. |

The current native client uses Unreal Engine. The proposal's earlier engine and
private proving-project details do not define the present runtime.
