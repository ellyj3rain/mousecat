# Mousecat Roadmap

## Current Milestone

`[A1]` establishes the working local substrate: one MCP server, one CLI, source-owned skill buttons, skill frameworks, work permits, tool boundaries, and route descriptors.

## Forward Work

| Track | Purpose |
|---|---|
| Host widgets | Render `mousecat.visualize` snapshots inside JetBrains, Codex, Claude Code, Cursor, and CLI surfaces. |
| Upstream adapters | Add live adapters for Neo, GitHub, browser, and custom tools behind explicit permits. |
| Credential providers | Bind credential references to OS keychain, environment, and host-managed identity without returning secret values. |
| Persistent state | Add local untracked `.mousecat/` state for queues, audit events, route cache, and session dockets. |
| Neo bridge | Export Mousecat skills, frameworks, permits, and route facts in Neo-compatible graph records. |
| OSS release | Ratify license, package name, release boundary, contribution policy, and publication path. |

## Non-Goals For A1

Mousecat does not execute upstream tools automatically, store secrets, publish packages, expose private Z-Library state, or import Neo source.
